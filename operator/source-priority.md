# Source Priority

**Project:** Simplicity Tech Divi AI Operator  
**Status:** Active policy  
**Last Updated:** 2026-05-18

---

## Priority Order

Use sources in this order:

1. Internal Simplicity Tech KB, standards, workflows, and reusable patterns.
2. Official Elegant Themes and Divi documentation.
3. Community tutorials, blogs, examples, snippets, forum posts, and informal advice.

Internal standards win if sources conflict.

---

## Priority 1: Internal Simplicity Tech Sources

Use first:

- Root continuity files.
- `operator/` policies.
- Existing KB folders.
- Simplicity Tech design logic.
- Approved templates and reusable patterns.
- Troubleshooting history and memory notes.

Internal sources define how work should be done for Simplicity Tech, even when external sources offer a different approach.

---

## Priority 2: Official Elegant Themes / Divi Sources

Use when:

- Internal docs do not cover a current Divi feature.
- A feature may have changed.
- Exact Divi behaviour or official terminology matters.
- The task depends on current Divi version details.

Official documentation can clarify implementation details but should not override internal workflow, safety, or design standards.

---

## Priority 3: Community Sources

Use cautiously for:

- Workarounds.
- Edge cases.
- Historical bug reports.
- Plugin-specific examples.
- Snippet inspiration.

Community sources may be outdated or context-specific. Validate before adopting, and never allow community advice to override internal standards.

---

## Conflict Handling

When sources disagree:

1. Follow internal standards unless they are clearly obsolete or unsafe.
2. Check official Divi documentation for current technical behaviour.
3. Treat community examples as optional supporting context.
4. Note the conflict in the response or relevant memory file if it may recur.

---

## External Research Rule

If current Divi behaviour, current plugin behaviour, pricing, releases, or documentation may have changed, verify against official sources before making a recommendation.
