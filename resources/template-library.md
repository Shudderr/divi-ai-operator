**Common Patterns:**
- Lift on hover (translateY)
- Grow on hover (scale)
- Shadow on hover
- Color shift
- Icon rotate

**Create as OGPs:**
```
Preset Manager → Create Option Group Preset
Name: "Hover - Lift"
Settings:
- Transform → translateY(-8px)
- Box Shadow → 0 8px 16px rgba(0,0,0,0.1)
- Transition → 0.3s ease

Apply via stacked presets
```

### Customizing Templates

**Best Practices:**
```
DO:
✓ Use Find & Replace for colors
✓ Update variables instead of modules
✓ Edit presets, not individual elements
✓ Test all breakpoints after import
✓ Clear cache after major changes

DON'T:
✗ Hardcode colors (use variables)
✗ Delete presets without checking usage
✗ Skip mobile testing
✗ Forget to export your custom version
```

## Troubleshooting Imports

### Common Issues

**Import fails:**
- File too large (> 10MB)
- Wrong file format (must be .json)
- Browser upload limit
- Solution: Import in smaller chunks

**Presets don't work:**
- Variables imported after presets
- Variables not saved
- Solution: Import variables first, click Save

**Sections look broken:**
- Missing dependencies (presets/variables)
- Divi version mismatch
- Solution: Check Divi version, re-import dependencies
