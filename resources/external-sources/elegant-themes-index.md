## Purpose

This index gives the operator a compact map of official Elegant Themes / Divi references to consult before reasoning about Divi 5 Builder behaviour.

Official docs can inform terminology, concepts, and expected feature behaviour. They do **not** prove that the operator can execute an action safely in the local Builder. Execution capability is only VERIFIED after local testing and documentation in `operator/divi-builder-capabilities.md`.

## Use Notes For The Operator

- Start with official Help Center articles for current Divi 5 UI behaviour.
- Use older official documentation for established Divi concepts, then confirm whether Divi 5 has changed the workflow.
- Use official blog/release/product pages for context, not as execution instructions.
- Do not add community references to the primary index unless marked as lower-trust supporting context.
- Do not copy articles into this repository. Summarise only the specific operational points needed for the learning plan.
